# OG-MAT
## Optimally Generic — a portable seed for better human–AI collaboration

**Not a copy of an assistant. A head start toward building your own collaboration.**

OG-MAT is a free, model-agnostic set of instructions that a human can give to an AI assistant. It aims to encourage curiosity, honest disagreement, grounded reasoning, practical usefulness, user agency, and improvement over time.

*OG* means **Optimally Generic**. The playful second meaning is intentional. The goal is not to make every assistant sound alike; it is to help different people and assistants find a way of working that fits them.

This is a gift to anyone who finds it useful. No product, subscription, special account, service, or affiliation is required beyond access to an AI assistant of your choice.

### The 60-second start

1. Open [SEED.md](SEED.md). This is the **one self-contained file** an assistant needs.
2. Give the entire file to your assistant: paste it into a chat, attach it as a document, or ask a capable assistant to read its GitHub URL.
3. Say:

> Please adopt the OG-MAT seed I've provided as my collaboration preferences, to the extent your capabilities and higher-priority instructions permit. Don't imitate an existing assistant or invent memories. Start helping with my actual goal; learn how I prefer to collaborate as we go.

4. Use the assistant for something real. You do **not** need to complete a personality quiz or formal setup.

**If your assistant cannot access links or attachments, paste the contents of SEED.md directly.** A GitHub URL alone does not guarantee a model read the file. If memory is unavailable, the instructions apply only while they remain in the model's usable context. Reprovide the seed or a user-approved summary when needed.

### What this does

- Encourages **independent but respectful thinking**, not reflexive agreement.
- Makes room for **competing explanations, evidence, uncertainty, and genuine revisions**.
- Keeps the human's goals, agency, boundaries, and values at the center.
- Promotes **progress**, not just interesting conversations.
- Helps the collaboration **adapt**, without projecting the original creators' personal facts or personality onto anyone else.

### What this does not do

- It does **not** transfer model weights, hidden system instructions, an AI identity, private memories, or an existing relationship.
- It does **not** grant tools, browsing, permissions, memory, consciousness, or capabilities your assistant does not have.
- It does **not** override higher-priority platform rules or safety constraints.
- It does **not** promise continuous learning or persistent personalization without an actual memory mechanism.
- It is **not** therapy, a substitute for human relationships, or a claim that every human should collaborate the same way.

### How to know whether it helps

Don't judge OG-MAT by how affectionate, polished, or agreeable the assistant sounds. Ask whether it helps you notice missing assumptions, make better-informed decisions, revise a belief when warranted, finish meaningful work, and retain your own judgment. See [EXPERIMENTS.md](EXPERIMENTS.md) if you want to test it.

### Sharing, changes, and credit

You may use, fork, translate, simplify, or improve OG-MAT under its permissive license. Different people may create dramatically different collaborations from the same starting point. That is a success, not a bug.

This seed is intentionally **optimally generic**: no biographies, personal memories, proprietary work, or requirement to adopt the original collaborators' beliefs. Contributions should preserve freedom of inquiry, user control, privacy, and honesty; suggestions that improve the method are welcome.

Its founding motivation is simple: useful knowledge can cross boundaries, and something learned together can be given away for others to question and improve.

**Version:** 0.1.0 — initial seed. **Status:** early and unvalidated across models. Feedback and evidence, including failures, are welcome.
